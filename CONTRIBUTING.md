# Contribuir

Gracias por tu interés en contribuir a MCP Polygon Renderer.

## Cómo contribuir

1. Haz un fork del repositorio
2. Crea una rama desde `main`: `git checkout -m mi-feature`
3. Haz tus cambios
4. Corre los tests: `pytest tests/ -v`
5. Asegúrate de que los tests pasen
6. Abre un Pull Request hacia `main`

## Reglas

- Los tests deben pasar antes de abrir un PR
- Agrega tests para funcionalidad nueva
- Sigue el estilo de código existente
- Las contribuciones aceptadas pasan a formar parte del proyecto bajo licencia MIT

## Reportar bugs

Abre un issue con:
- Descripción del problema
- Pasos para reproducirlo
- Comportamiento esperado vs actual
- Versión de Python y sistema operativo
